# Calendário Olímpico do NOIC

Feeds públicos iCalendar com os eventos aprovados do Calendário Olímpico do NOIC.

- **Calendário completo:** <https://goncalofrankefranco.github.io/noic-calendario-feed/calendar.ics>
- **Feed de uma olimpíada:** `https://goncalofrankefranco.github.io/noic-calendario-feed/olimpiadas/<competition_id>.ics`

A página do calendário do NOIC mostra o link específico no detalhe de cada olimpíada. No Google Calendar, escolha **Outros calendários → + → De URL** e cole o link do calendário completo ou da olimpíada que deseja acompanhar. A assinatura acompanha mudanças no feed; o Google controla a frequência de atualização.

Os downloads `.ics` da página são cópias estáticas. Use os URLs acima para assinar as atualizações.
