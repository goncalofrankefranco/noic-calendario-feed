# Calendário Olímpico do NOIC

Este repositório hospeda o feed público iCalendar com as datas aprovadas do Calendário Olímpico do NOIC.

**Endereço do feed:** <https://goncalofrankefranco.github.io/noic-calendario-feed/calendar.ics>

No Google Calendar, use **Outros calendários → De URL** e cole o endereço acima. Inscreva-se pelo URL; importar o arquivo cria uma cópia que não acompanha atualizações. O Google controla a frequência com que atualiza calendários inscritos.

As datas seguem o fuso `America/Sao_Paulo`. O feed é atualizado após a revisão manual e mesclagem dos PRs diários de datas.
